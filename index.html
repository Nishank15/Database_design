Enterprise System Architecture & DBMS Model

Project Credits:
Developer: NISHANK CHHIPA (Reg No: 25BCE1642)
Course: B.Tech CSE • Semester 3 DBMS Full-Stack Portal
Relational Architecture (8 Normalized 3NF Tables):
hostel_blocks, students, meal_categories, daily_menus, rebate_requests, meal_swipes, monthly_bills, audit_log, users_auth.
Date-Aware PL/SQL Triggers:
• trg_prevent_duplicate_swipe: Prevents double-swiping for the same category on the same calendar day (Error -20001).
• trg_rebate_swipe_guard: Prohibits turnstile access if student is on active approved rebate leave (Error -20002).
• trg_audit_wallet_change: Captures all wallet balance modifications in immutable audit trail.
PL/SQL Package mess_ops_pkg:
• calculate_monthly_billing: Explicit cursors c_swipes & c_rebates, cursor FOR loops, atomic MERGE INTO monthly_bills.
• record_turnstile_swipe: Real-time tariff deduction & status reporting.
• register_student & apply_rebate: Transactional workflows.
Full-Stack Integrations:
• Java 25 HTTP Backend with Oracle JDBC (CallableStatement & PreparedStatement).
• Standalone Python ODBC Reporting Tool (reports/odbc_audit.py).
